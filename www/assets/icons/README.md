# الأيقونات (icons)

هذا المجلد يحتاج أيقونتين قبل البناء النهائي:

- `icon-192.png` — 192×192 بكسل
- `icon-512.png` — 512×512 بكسل

لا يمكن توليدهما هنا (بيئة بلا اتصال إنترنت ولا أدوات تصميم). صمّمهما بأي
أداة (Figma/Canva/Photoshop) بما يعكس هوية "جزيرة الجليد" (جليد/كرات/ألوان
زرقاء-ذهبية المستخدمة في الواجهة)، أو استخدم مولّد أيقونات Android Studio
(Image Asset Studio) الذي يبني تلقائيًا كل القياسات المطلوبة من صورة واحدة
عالية الدقة بعد `npx cap add android`.
