## عليك إكماله يدويًا (بالترتيب المقترح)

### 1. الأصول الثنائية (تحتاج إنترنت لديك)
- [ ] تنزيل 18 ملف صوت حسب `www/assets/sounds/README.md`
- [ ] تنزيل/تثبيت `matter.min.js` حسب `www/assets/libs/README.md`
- [ ] تصميم أيقونتي `icon-192.png` و`icon-512.png` حسب
      `www/assets/icons/README.md`

### 2. مشروع Capacitor (يحتاج Node.js مثبت لديك محليًا)
```bash
npm install
npx cap add android
npx cap sync android
```
هذا يولّد مجلد `android/` كاملًا (مشروع Android Studio حقيقي). التزم
برفعه إلى GitHub بعد إنشائه (هذا شائع ومتوقّع في مشاريع Capacitor).

### 3. الفوترة (In-App Purchases)
- [ ] اتبع `docs/IAP_SETUP.md` بالكامل خطوة بخطوة

### 4. الهوية والتوقيع
- [ ] راجع `appId` في `capacitor.config.json` (حاليًا
      `com.sympraxis.iceisland` كقيمة مبدئية) — **لا يمكن تغييره بعد
      أول نشر على المتجر**
- [ ] أنشئ مفتاح توقيع (keystore) واحتفظ بنسخة احتياطية آمنة منه —
      فقدانه يعني عدم القدرة على تحديث التطبيق مستقبلًا أبدًا
- [ ] لا ترفع ملف الـ keystore لأي مستودع (مستثنى بالفعل عبر
      `.gitignore`)

### 5. بطاقة العرض والخصوصية
- [ ] انشر `docs/PRIVACY_POLICY.md` على رابط عام (مثلًا GitHub Pages
      من هذا المستودع نفسه) وضع الرابط في Play Console
- [ ] استخدم `docs/STORE_LISTING.md` كمسودة، وأضف لقطات شاشة حقيقية
      بعد تشغيل التطبيق على جهاز/محاكي
- [ ] أكمل استبيان Content Rating و Data Safety في Play Console بصدق

### 6. اختبار نهائي قبل الرفع
- [ ] شغّل التطبيق في وضع "طيران" (Airplane mode) للتأكد من عمله بلا
      إنترنت بعد إكمال الخطوة 1
- [ ] جرّب كل الأزرار الستة في تبويب "كوين" بالمتجر (كانت 4 منها معطوبة
      في النسخة الأصلية)
- [ ] راجع حجم الأزرار على شاشة صغيرة فعليًا (الكود يستهدف الحد الأدنى
      48dp المطلوب من Google Play، لكن التحقق البصري الفعلي على جهاز
      حقيقي ضروري)

## تنويه مهم
لم يكن ممكنًا اختبار هذا الكود داخل متصفح فعلي أو محاكي أندرويد أثناء
إعداد هذه الحزمة (بيئة بلا شاشة عرض ولا اتصال إنترنت). راجع اللعبة على
جهازك خطوة بخطوة بعد كل تعديل تجريه، خصوصًا قبل أول رفع فعلي للمتجر.
